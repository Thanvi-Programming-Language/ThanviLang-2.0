# ThanviLang 2.0

ThanviLang 2.0 is the next generation of the
Thanvi Programming Language.

## Features

- WebApp syntax
- Pages
- Navigation
- Hero sections
- Buttons
- Cards
- Themes
- `.thanvi` source files
- Python-based development runtime

## Example

```thanvi
app "Thanvi WebApp" {

    version "2.0.0"

    page "/" {

        hero {
            title "Build with Thanvi"
            subtitle "Create modern web applications."
        }

    }
}
